# Lumora downloads

Public download-only repository for Lumora Windows builds.

This repository intentionally contains **no Lumora application source code**. It exists so the signed-test installer can be downloaded without exposing the private development repository.

## Windows installer

Download the latest installer from the [GitHub Releases page](https://github.com/NickIT64/Lumora-downloads/releases).

The `Lumora-Setup-0.1.4.exe` asset is a Windows 10/11 64-bit NSIS installer. It bundles the Python voice runtime; voice models are fetched once on first launch if they are not already present.

Project website: [lumora-two-sigma.vercel.app](https://lumora-two-sigma.vercel.app/)
